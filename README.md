# Soukassou Pro

Application web (PWA) de gestion commerciale : caisse, livraisons, factures, mensualités, contrats PDF, fournisseurs.
Les données sont stockées dans le navigateur (localStorage) : pensez à utiliser **Paramètres > Exporter la sauvegarde**.

Fichiers : `index.html`, `app.js`, `sw.js`, `manifest.json`, `icon-192.png`, `icon-512.png` (à garder dans le même dossier).
